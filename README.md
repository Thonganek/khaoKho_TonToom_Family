# Above the Clouds — เขาค้อ

ภาพยนตร์ครอบครัวจากภาพถ่ายทริปเขาค้อ เล่นได้ในเบราว์เซอร์ทุกเครื่อง (คอมพิวเตอร์ · iPad · มือถือ)
ดูออนไลน์: https://thonganek.github.io/khaoKho_TonToom_Family/

ภาพทุกใบรวมกันเป็น “หัวใจ” ช่องในหัวใจจะเปิดออกมาเป็นฉากทีละภาพ แล้วกลับเข้าหัวใจด้วยท่าที่ต่างกันไป
(ย่อโค้งเข้า · หมุนเข้า · จางเป็นประกายทอง · แตกเป็นชิ้นแล้วหมุนวนกลับ) ช่องที่แสดงแล้วจะกลายเป็นภาพสีเต็ม
จนตอนจบหัวใจเต็มทุกช่อง โทนภาพสว่างตลอดเรื่อง

## วิธีดู
- เปิด `index.html` ด้วย Chrome / Edge / Safari ภาพยนตร์จะเริ่มเล่นเองและวนต่อเนื่อง
- แตะจอ = เล่น/หยุด · แตะสองครั้ง = เต็มจอ · กดค้าง = แผงตัดต่อ (เพิ่มเพลง, บันทึกเป็นวิดีโอ, จัดลำดับภาพ)
- คีย์บอร์ด: `Space` เล่น/หยุด · `←` `→` เปลี่ยนบท · `F` เต็มจอ · `M` เสียง · `P` แผงตัดต่อ · `R` เริ่มใหม่

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css`, `script.js` | ตัวภาพยนตร์ |
| `film-edit.js` | บทตัดต่อ: ลำดับบท ภาพในแต่ละฉาก และคำบรรยาย |
| `photos-manifest.js` | รายชื่อภาพในโฟลเดอร์ `คัดแล้ว` (สร้างอัตโนมัติ) |
| `build-manifest.ps1` / `build-manifest.js` | สร้าง `photos-manifest.js` ใหม่เมื่อเพิ่ม/ลบภาพ |
| `share-card.html`, `build-share-image.ps1` | สร้างภาพตัวอย่างลิงก์รูปหัวใจ `og-heart.jpg` และไอคอน `apple-touch-icon.png` |
| `คัดแล้ว/` | ภาพต้นฉบับ (ไม่มีการแก้ไขไฟล์ภาพ) |

## เปลี่ยนภาพ
1. ใส่/ลบภาพในโฟลเดอร์ `คัดแล้ว`
2. รัน `powershell -ExecutionPolicy Bypass -File build-manifest.ps1`
3. ภาพที่ไม่อยู่ใน `film-edit.js` จะถูกจัดเข้าบท “ช่วงเวลาดี ๆ” ให้อัตโนมัติ
4. รัน `powershell -ExecutionPolicy Bypass -File build-share-image.ps1` เพื่อทำภาพหัวใจสำหรับแชร์ลิงก์ใหม่
   แล้วเปลี่ยนเลข `?v=1` ใน `index.html` (บรรทัด `og:image`) เป็นเลขใหม่ เพื่อให้ LINE / Facebook ดึงภาพใหม่

## แชร์ลิงก์ใน LINE / Facebook
ลิงก์จะแสดงภาพหัวใจจากภาพถ่ายทุกใบ หาก LINE ยังแสดงภาพเก่า (LINE จำภาพตัวอย่างไว้ระยะหนึ่ง)
ล้างแคชได้ที่ https://poker.line.naver.jp/ · ของ Facebook ใช้ https://developers.facebook.com/tools/debug/
